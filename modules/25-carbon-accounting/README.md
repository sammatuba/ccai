# Module 25 — AI for Carbon Accounting (MRV)

**Tutorial:** Estimating Coal Power Plant Operation from Satellite Images

Computer vision on Sentinel-2 imagery to detect cooling-tower plumes and estimate plant
operational status (ON/OFF) as a proxy signal for emissions monitoring, reporting, and
verification (MRV). Covers unbalanced-data metrics (balanced accuracy), cloud filtering,
and the limits of proxies.

- Notebook: [Coal_Power_MRV_Satellite_CV.ipynb](Coal_Power_MRV_Satellite_CV.ipynb)
