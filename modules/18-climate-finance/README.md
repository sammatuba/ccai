# Module 18 — AI for Climate Finance

**Tutorial:** Hurricane Wind Value-at-Risk

The catastrophe-modeling chain — hazard → exposure → vulnerability → loss — run with
CLIMADA, driven by a generative AI weather ensemble (WeatherNext cyclone, 50 members,
Hurricane Helene), to compute county-level wind Value-at-Risk. Distinguishes single-event
event-VaR from annualized Average Annual Loss (AAL).

- Notebook: [Hurricane_Wind_VaR.ipynb](Hurricane_Wind_VaR.ipynb)
